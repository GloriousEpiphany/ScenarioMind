# Agent提示词设定规则说明

## 一、提示词体系架构（建议配图1：双层提示词架构图）

本系统采用双层提示词架构，通过系统提示词（System Prompt）和每日决策提示词（Daily Decision Prompt）的协同作用，引导AI智能体完成股票交易决策任务。系统提示词负责建立Agent的长期角色定位、投资理念和标准化工作流程，而每日决策提示词则根据当前交易日的账户状态（资金、市值、仓位比例）动态生成，为Agent提供实时的决策上下文。这种设计既保证了Agent行为的一致性，又使其能够根据市场状态做出适应性调整。

## 二、系统提示词核心内容（建议配图2：四步工作流程图）

系统提示词的设计遵循"角色明确、流程规范、规则清晰"三大原则。首先，通过明确Agent作为"专业股票投资顾问"的角色定位，强调"资金闲置是最大浪费"的投资理念，使其具备主动寻找投资机会的思维模式。其次，采用强制性的四步工作流程：步骤1查看持仓（必须调用get_portfolio）、步骤2数据收集（分析5-6只股票的技术指标）、步骤3执行交易（必须通过工具调用）、步骤4文字总结。最后，通过详细的买入卖出条件、仓位管理指南（0-30%必须积极买入，30-80%合理区间，>80%不再买入）和技术指标参考（RSI、MACD、MA均线），为Agent提供可操作的决策依据。

## 三、动态提示词机制（建议配图3：仓位区间与操作建议表）

每日决策提示词采用模板化设计，根据当前交易日的账户状态动态生成。该提示词不仅包含资金、市值、收益率等关键财务指标，更重要的是突出当前仓位比例，并根据仓位水平给出差异化的操作建议。当仓位低于30%时，提示词会强调"资金闲置是最大的浪费"，引导Agent积极建仓；当仓位处于30-70%时，提示Agent精选个股、平衡买卖；当仓位超过70%时，则提示谨慎加仓、关注卖出机会。这种动态调整机制确保了Agent能够根据实际投资状态做出适应性决策，避免过度保守或过度激进。

## 四、工具调用约束与风险控制（建议配图4：工具调用交互流程图）

系统通过严格的工具调用约束，确保Agent的决策能够转化为实际交易行为。在系统提示词中，明确要求Agent必须通过调用`buy_stock`或`sell_stock`工具来执行交易，禁止仅在文字中描述交易意图。同时，通过Function Calling机制，将5个核心工具（get_stock_history、get_technical_indicators、get_portfolio、buy_stock、sell_stock）的定义与提示词内容紧密结合，使Agent能够理解每个工具的功能、参数要求和返回格式。在风险控制方面，通过仓位区间表、强制止损止盈条件（亏损-8%止损、盈利15%止盈）和明确的技术指标判断标准，构建了一个既鼓励积极投资又严格控制风险的决策框架。

## 附录：核心提示词内容摘要

### 系统提示词核心要素
- **角色定位**：专业股票投资顾问，管理100万账户
- **投资理念**：资金闲置是最大浪费，合理仓位30%-80%
- **工作流程**：四步强制流程（查看持仓→数据收集→执行交易→文字总结）
- **买入条件**：RSI<50、MACD金叉、价格站上MA5等6个条件
- **卖出条件**：止损-8%、止盈15%、RSI>75、MACD死叉等强制条件
- **仓位管理**：根据仓位区间给出差异化操作建议

### 每日决策提示词动态变量
- `current_date`：当前交易日期
- `cash`：可用资金
- `market_value`：持仓市值
- `total_return`：总收益率
- `position_ratio`：当前仓位比例（关键变量）

### 工具定义（Function Calling格式）
- **查询类工具**：get_stock_history（K线数据）、get_technical_indicators（技术指标）、get_portfolio（持仓信息）
- **交易类工具**：buy_stock（买入，需资金验证）、sell_stock（卖出，需持仓验证）
