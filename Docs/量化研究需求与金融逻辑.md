# 量化研究需求与金融逻辑

更新：2026-11-08。本文替代早期 V4 建设总纲，区分现行能力、条件能力和可选实验。实现证据见[当前进度](量化研究实现进度.md)，严格数值引擎契约见[V3 手册](V3严格引擎手册.md)。

## 1. 产品回答什么

围绕当前实际持仓，说明已经知道什么、哪些条件可能改变现金流或风险、每只持仓如何暴露、什么事实会推翻判断。交付有来源的条件研究、数值模型适用范围和持续复核记录。研究完成不等于投资效果得到验证，也不等于可以发布数量化交易指令。

不以收集全部历史公告、逐字阅读全部年报、取得所有新闻源或生成更多 Agent 作为完成标准。任何新增功能必须说明对应的决策、必需输入、可验证输出和失败影响。

## 2. 金融推演顺序

1. 冻结账户、真实行情、研究时点和可见证据；核对价格口径、财务报告期、单位与修订版本。
2. 分离事实、推导和假设。识别新到达的旧资料，不能把接收日期当事件发生日期。
3. 独立研究公司现金流、行业暴露、市场与政策条件、新闻和资金行为；缺失证据限制相应结论。
4. 围绕收入、成本、融资、资本开支、折现率与风险溢价解释传导。检验预期是否已反映、共同原因、替代解释和反证；没有预期数据不能宣称识别了市场惊喜。
5. 综合为有触发条件、失效条件和父子关系的竞争情景，逐只覆盖持仓；假设优先级不是概率。
6. 调用可复现量化工具，分别说明基准因子分布、事件条件影响和经过校准的概率。不能把零附加冲击的基准路径贴上事件标签。
7. 比较不交易、现金储备和减少直接暴露的条件、代价及残余风险。数值仓位与数量必须另过联合分布、交易资格、成本和优化校验。
8. 独立审查引用、机制和反证；新原件触发旧论点复核；真正到期后结算原始预测，不回填过去原点。

## 3. 有效需求与数据范围

| 需求 | 范围与验收 |
|---|---|
| 当前组合研究 | 默认最近 550 个自然日的行情；真实来源绑定数值面板至少 126 行。窗口选择不代表最优预测能力 |
| 公司基本面 | 相关报告期、可比口径、最新修订和重大事件。跨期比较按问题选择，不按固定古早起年无限扩张 |
| 历史压力与样本外检验 | 仅在明确周期、制度或尾部风险问题时扩展。旧行情、公司行动和交易日历仍可能必要 |
| 文本取证 | 保存完整原件和哈希；完整读取目录，再按论点检索并阅读准确原文片段，保存偏移与引用。独立审查可要求补读反证；局部阅读不称全文审阅 |
| 宏观新闻 | 普通新任务将 CCTV 作为附加来源，缺失明确显示；必须读取双交易所基准与持仓财务/行业暴露。用户明确要求完整节目分析时仍强制完整采集 |
| 历史版本证明 | 仅对声称历史可见的特定原件核验独立捕获。当前取证无需把所有文档还原到首发日；本系统 known_at 永不倒填 |
| 自动跟踪 | 持久化反馈、原请求预算、无递归子跟踪；先结算到期审计，再执行可能耗时的模型复核 |

2008—2015 年以及 2016 年公告不再是当前预测的必需补采范围。并非年份本身使数据无效，而是现有主链不消费该旧实验，也没有受控比较证明补齐它改善当前预测。已退休固定 2012 年半年报事件桥接、固定 002230 的事件片段模型与专属审计；保留通用原件解析、复权、来源绑定和归档证明。

## 4. 不得混淆的统计对象

- “未来窗口出现任意公告”只描述发布频率，不描述利好、利空、重大事件或价格方向。
- above/within/below 表示实绩相对公司自己发布的利润预告区间；不是分析师一致预期误差，更不是因果收益。
- 事后选择的跨发行人对照只检验解析与类别覆盖；不能拿来估计目标股票分支概率。
- 公告后的收益漂移、条件相关性与事件因果影响分别陈述。重叠累计报告期和重叠窗口不能充作独立样本。
- 既有 1/5/20/60 日、每期 50 个非重叠窗口的公告频率协议是可选前瞻实验。60 日协议积累很慢，不再作为普通条件研究的发布前置条件；原协议阈值、预测和结果不改写。

## 5. Agent 开发和完成条件

研究总控规划七项职责并检查依赖：宏观、公司、情绪独立；情景综合；量化；组合；跟踪。角色必须实际使用受控工具、检查反馈、接受独立 critic，并持久化预算、输入和结果。独立上下文不等于不同模型的统计独立性。

确定性数据采集与数值计算应由工具完成，不为了“Agent 化”重复包裹模型。引用必须来自冻结证据且实际读过；原件研究进一步核验精确偏移与哈希。模型不能创建价格、财务数值、概率或数值 provenance。

工程完成、条件研究完成、数值验收通过分开记录。预算耗尽、缺失来源、未校准与不可行不得包装为成功。实际职责审查见[Agent 验收](Agent职责与实现验收.md)。

## 6. 新旧合同与删除规则

新任务采用版本化来源范围和提示词。旧任务缺少 cctv_required 时继续旧的完整节目要求；同一运行 ID 不修改冻结来源规则。公告研究 v2 保留全文读取合同，v3 使用精确片段合同。旧结果与旧数据库可继续只读审计。

只删除无当前调用者、被替代且不承担证据保存责任的代码。不能按 historical、legacy 或年份关键词批量删行情、复权与时间可见性模块。删除入口必须同时清理注册、测试和文档；保留的兼容路径须有明确调用者和恢复测试。

## 7. 目前不能承诺的能力

量化桥接已运行来源绑定拟合和零附加冲击路径，尚不代表每条语义情景已映射为可估计的 StateChange，也没有完成目标发行人的语义概率校准。严格数值引擎只在真实数据及验证条件满足时发布结果。未来窗口未成熟不能靠 API 或修改时钟解决；研究工具可以完成，预测准确性需要真实样本外验证。

旧 v1 未完成组合执行协议已退休，返回 requires_new_request，不再提供无效重试；需按当前目标创建新任务。旧证据、预算、已完成报告和可恢复的 v2 合同不改写。
