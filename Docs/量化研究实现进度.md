## 工程交付

- `ResearchController` 用模型制定、修订结构化计划并选择就绪任务；服务端固定必需职责与依赖。已执行任务不能改写，漏任务或预算耗尽不能通过总控 critic。
- 宏观、公司、情绪保持独立上下文；情景和组合读取经过审查的候选。原件分页、正文完整性、已读引用及逐证券机制证据检查保留。
- 量化输入在截止时点冻结前自动采集：原始行情、双交易所基准、巨潮公司行动和逐行来源绑定收益面板。量化 Agent 与独立 critic 调用 estimate/simulate/optimize/validate，只接受注册实验 ID；实际拟合、同步抽样和独立验证不接受模型自填数组、概率或阈值。
- 组合评估读取实际数值结果和阻断。条件总收益路径不冒充现金股息持仓路径或经过校准的事件概率；调用严格优化器入口也不等于前置校准与执行凭证已经通过。
- 研究通过后启动持久化跟踪：新证据或每 24 小时复核进入反馈队列，最多 3 次，每次沿用父任务调用预算，子任务不再扩展跟踪树。新研究重新冻结原件并强制读取触发证据。机器停机期间不补发历史原点。
- 前瞻工作器在上海时间 15:30 后核验双交易所实际收盘，再发出当天原点并调用原有到期审计。保留 1/5/20/60 日、各 50 个不重叠窗口的原评价协议。
- Wayback、Arquivo、Common Crawl 的独立捕获支持离线复验；显式 HTTP/HTTPS 别名仍需同域同路径和字节一致。统一离线验证器检查原件与捕获链，独立公共捕获时间与本系统 `known_at` 分开。

实现与边界见 [Agent 验收矩阵](Agent职责与实现验收.md)，运行/恢复命令见 [持仓研究手册](持仓情景研究手册.md)。新增免费数据入口与可选 Key 获取说明见 [数据接入](免费数据API接入.md)。这些新数据入口无需新 API Key；付费新闻权限不是历史可见性的替代品。
