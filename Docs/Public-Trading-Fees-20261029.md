# 深市普通 A 股公共费用核验（2026-10-29）

核验范围为普通 A 股竞价交易，不包含港股通、融资融券、大宗交易、存托凭证、基金或债券。公开规则可以免费查询；本表不替代账户佣金合同，也没有写入任何真实账户费率。

经手费和证管费通常已包含在公布的佣金口径内。公开规则列出费用组成，不能直接把所有费率再加到用户佣金上，否则可能重复收费。实际账户比例、是否同时包含过户费、按委托还是逐笔成交合并计费、各项取整规则，仍需账户合同或券商交割数据。此轮没有连接券商私人账户、没有找到可匿名查询某个账户佣金的公开接口，也没有推定默认佣金。

中国结算[收费索引](https://www.chinaclear.cn/zdjs/fbzyls/service_tlist/code_0.shtml)列出的最新深圳表日期为 2025-12-31。本轮已定位到[该官方 PDF](https://www.chinaclear.cn/zdjs/fbzyls/202512/a59388fbfa714c5fa546784891a42e30/files/深圳市场证券登记结算业务收费及代收税费一览表.pdf)，但网页读取超时；本机 HTTPS 返回 `200 text/html`，内容不是 PDF。未保存伪 PDF、未据此声称读到该表正文。过户费数值目前由上交所当前官方服务页直接支持；中国结算该版原件复核仍有采集限制。

分红税不能填入固定卖出税率代替。税务总局[财税〔2015〕101 号](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)规定，个人公开市场股票持有超过一年时股息红利暂免税；一年以内按持有期限适用差别化税负，派发时暂不扣缴，转让时由登记结算公司按持有期限计算、由托管机构扣收。因此，历史分红公告和当前总股数不足以计算卖出时补扣税，需要持有批次、登记权益及扣税明细。

工程对应：`FeeSchedule` 仅接受有账户出处的显式分币及计费归并合同；`RegisteredCashEntitlement` 仅接受已登记、实际支付日明确且税额最终确定的净分红现金。卖出相关的递延补扣税仍缺券商批次数据，必须保留阻断。
