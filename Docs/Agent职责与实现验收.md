# Agent 职责与实现验收

审查日期：2026-11-08。依据当前需求与 `CONTEXT.md`。这里的 Agent 指项目运行的研究角色，不是开发时的多个助手。主链必须有模型动态工具选择、工具结果检查、独立反证、失败后补证、预算和持久化恢复，不能把固定 Python 步骤或提示词角色名当作自治完成。

## 逐项核对

| 规范职责 | 实际入口与输出 | 工程状态与边界 |
|---|---|---|
| 研究总控 | `ResearchController`、`ResearchPlan`、独立 critic | 已接入新任务主入口；模型制定/修订任务问题与优先级、选择满足依赖的任务；服务端禁止漏角色、跳依赖、改写已执行任务或以预算耗尽冒充完成 |
| 数据与证据 | `DeductiveResearchPipeline`、冻结 PIT 分页、公告检索/正文工具 | 有来源/哈希/时间及缺口校验；采集仍主要在模型研究前完成，不能声称研究中任意新数据域都可自动补齐 |
| 事件与宏观 | `macro` + 独立 critic | 真实工具循环，沪深基准与相关公司机制证据要求；新任务 CCTV 为附加来源，明确要求节目分析时仍完整采集；本轮确认不读前序专家意见 |
| 公司与产业链 | `company` + 独立 critic | 财务/行业必需资料全量分页、逐股假设及原始证据绑定；实际供应链资料不足时仍需报告缺口 |
| 预期与资金 | `sentiment` + 独立 critic | 原新闻/派生文本特征/资金流分别查询；本轮补全分页与上下文隔离；文本语气不能冒充真实投资者预期 |
| 未来推演 | `scenario` + 独立 critic | 已审查候选综合、父子路径、触发/失效条件、逐股证据；尚无经过真实数据校准的语义分支概率 |
| 量化研究 | 独立量化 AgentRuntime、critic、`quantitative_tools` | 已注册 estimate/simulate/optimize/validate；模型只选注册实验，四工具与每个实验的完成覆盖由服务端检查。实际因子拟合/零附加冲击基准抽样及独立验收接入，未把语义事件转换为已校准数值冲击；缺源、缺校准或执行凭证时明确 blocked |
| 组合决策 | `portfolio` 条件评估，`portfolio_policy/*` 独立求解/复核 | 已接收情景与实际量化工具结果；逐仓覆盖、不交易对照、对冲及独立审查保留。调用严格优化入口不意味着未通过的校准/执行闸门已通过 |
| 独立反证 | 每个研究角色独立 critic 上下文 | 排除研究者私有续写，只审查原工具证据与不可信候选；同模型不同上下文不是统计独立性。代码可否决模型的通过决定 |
| 跟踪复盘 | `research_tracking`、`research_worker`、既有 `issuer_evaluation` | 新证据/定期复核 → 持久化反馈 → 新总控任务；沿用预算、最多 3 次、无子跟踪递归。触发证据加入新冻结清单并强制读取；真实交易日才发原点，按原协议到期审计 |

此前待实现的总控规划、量化工具桥接和自动跟踪反馈已接入主链。总控、五位领域专家和量化专家均使用真实工具调用循环与独立审查，确定性采集和数值校验作为工具实现。不能据此宣称真实金融有效性或全部外部证据问题已解决：已有一份近期原件独立字节证明和真实三类跨发行人对照；这不等于目标发行人概率已校准，未经历的未来交易日不能提前成熟。

补充工程验收：数值输入在冻结前自动采集并逐行绑定；重开成功任务不重复计算；同一全局调用预算包含总控、量化和领域专家，报告修订也计入已用工具次数。跟踪使用真实时钟、SQLite 队列和租约，Windows 隐藏进程；不会在旧报告上覆盖新结论。每个运行契约保存计划、提示词、工具版本、数值策略和跟踪上限。

## 本轮已修复的验收漏洞

1. 前三专家只共享冻结原件、组合和任务目标；情景/组合阶段才接收同伴主张，避免顺序执行产生结论污染。
2. 公司与情绪专家读取全部必需工件，不能把首页当作全史；旧合同和明确要求完整节目的新任务保留 CCTV 完整性要求。
3. 最终假设、持仓与对冲引用需有实际读取记录；未读引用即使 critic 通过也返回修复。只检查最新候选，保留旧草稿轨迹。
4. 公告目录全页和每条引用的实际读取片段在循环内验收；偏移、原文和哈希必须一致。新 v3 不要求逐字读完整年报，旧 v2 合同保留。
5. 公司/情绪/情景每项假设按实体绑定原始机制证据。持仓情景 ID 还必须属于该证券；每只被对冲证券须有自己的原始机制证据。仅引用本股价格并拼接宏观证据不能通过。
6. 审查结果记录最终假设及评估输入哈希，运行契约升级。改变工具、预算、冻结输入或版本仍拒绝旧 ID 续跑。

专项测试在 `test_agent_evidence_gates.py`、`test_portfolio_research.py`、`test_advisory_runtime.py`、`test_issuer_document_research.py`；归档证明测试在 `test_historical_capture.py`。本次批准的真实原件复核已完成，累计模型 40/144、工具 30/112；完整最新组合报告仍按旧来源合同记录失败，不借此宣称预测有效。

本轮覆盖计划依赖、实际来源绑定拟合/抽样、实验 ID 边界、独立量化审查、跟踪幂等与预算、周末不发预测、免费归档字节证明、修订冲突和财报限定覆盖。最新全量结果、真实源采集结果及限制统一见 [当前进度](量化研究实现进度.md)，不将测试夹具视为真实市场或真实模型有效性验收。
