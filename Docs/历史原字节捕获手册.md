# 独立历史原字节捕获

此入口用于证明某个不可变公告 PDF 在独立归档服务的捕获时点已经存在。它不生成历史预测，不倒填本系统可见时间，也不解除样本量或校准门槛。

## 使用

先在独立研究库内准备已采集的巨潮 `disclosure_pdf_raw` 或 `cninfo-disclosure-pdf-v1` 正文工件。输入必须绑定原 PDF 字节和 SHA-256；OCR 文本不是原字节。原始来源 URL 来自工件，不能由模型任意指定。

```powershell
.tmp/advisory-venv/Scripts/python.exe main.py capture-historical-document `
  --db-path .tmp/independent-research.db `
  --run-id capture-example-01 `
  --original-ref disclosure:实际工件ID `
  --cutoff 2025-06-01T00:00:00+00:00 `
  --output .tmp/capture-example-01.json
```

需要显式直连时加 `--direct`，只作用于该请求会话，TLS 验证始终开启。默认使用环境网络配置，不在失败后静默换源。输出文件只新建不覆盖；恢复时使用原 run-id 和新输出文件名。

索引限定精确 URL、截止时间及最多 200 条；不宣称查询结果穷尽全部历史存档。HTTP 重定向、超过体积上限、时间不匹配或索引摘要不匹配均拒绝。只有 identity replay 的字节与当前原件完全相同，才生成正向历史重建证明。

## 结果

| 状态 | 含义 |
|---|---|
| `independent_historical_bytes_verified` | 至少一份捕获通过 URL/时间/摘要/原字节核验 |
| `no_capture_returned` | 本次限定查询成功但没有返回捕获；不证明全球无存档 |
| `archived_version_differs` | 独立捕获可信，但与当前冻结原件字节不同；不授予当前版本历史可得性 |
| `blocked` | 网络、响应、索引或证明验收失败；详细原因保留 |

非验证成功状态 CLI 退出码为 2。`captures`、`failures` 与 `http_refs` 应一起审阅；有一份匹配不代表其他候选也通过。成功请求有检查点；网络失败可按原契约恢复。空索引已冻结，需要以后重新查询时必须使用新 run-id。

`document_capture_proof` 引用原始工件、原始索引、replay 响应和各自哈希。`available_at` 是独立捕获时间；工件的 `known_at`/`ingested_at` 仍为本次真实接收时间。`verify_document_capture(repo, proof_ref, cutoff, at=...)` 从库内原字节独立复算，拒绝仅有自填成功标记、不同版本、晚于截止时间或错绑来源的证明。

### 不经过 CDX 查询 API 的公共 S3 索引

`--provider commoncrawl_s3 --collection CC-MAIN-2025-21` 显式选择公开 `cluster.idx` 和压缩 CDXJ 块，再获取 WARC；无需 AWS 账户或 API Key。该路径解决了本次查询 API 返回 504、公共 S3 仍可读的实际问题。保存 HTTP 206 原字节范围、索引前缀、块位置、WARC 和原 PDF，并在离线复验中重新核对每一层。

索引前缀最多 32 MiB，压缩块最多 4 MiB，解压索引最多 16 MiB；前缀未覆盖目标时明确阻断，不能报全球无存档。同一前缀的批量查询复用已解析索引，避免为每份文档重复解析大型文件。成功复验命令：

```powershell
.tmp/advisory-venv/Scripts/python.exe -m src.stock_app.cli capture-free-historical-document --db-path .tmp/recent-controls-1108.db --run-id recent-real-300125-s3 --original-ref disclosure:c2e492fe2309e3762b1c6889865bd289611bda4281834fd836d5dea968ce7c2e --cutoff 2025-06-01T00:00:00+00:00 --provider commoncrawl_s3 --collection CC-MAIN-2025-21 --archive-scheme http --direct --output .tmp/recent-real-capture-replay.json
```

输出文件必须不存在。同一成功任务复用已保存回执，不再次联网。

## 免费替代归档与 HTTP 别名

增加 `capture-free-historical-document`，支持 `--provider arquivo` 和 `--provider commoncrawl --collection CC-MAIN-2025-21`，其余 `--db-path/--run-id/--original-ref/--cutoff/--output` 与上述相同。Common Crawl 读取 CDX JSON 行并按索引 offset/length 获取 WARC 字节范围，核对 Content-Range、原 URL、WARC 日期、HTTP 状态及 SHA-1/SHA-256。压缩后扩展大小受限；不支持的 HTTP 内容编码明确阻断。Arquivo 核对 CDX、identity replay、Memento 时间和原字节。原始错误响应同样保留。

两个入口都接受 `--archive-scheme http`，用于显式检索同域同路径的历史 HTTP 别名；归档服务本身仍经 HTTPS 访问。不能通过该参数更换域名、路径或追加查询参数，最终仍须字节一致。

统一的 `verify_document_capture` 可离线复验三个提供者的证明。验证器匹配冻结文档的 URL、证券及原始 PDF 哈希，报告独立公共捕获时间。固定旧发行人的事件片段实验入口已退休。它仍不授予历史系统 PIT、原预测资格或合格样本数量。
