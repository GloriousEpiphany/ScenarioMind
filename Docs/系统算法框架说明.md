### 1.2 核心组件说明

#### 1.2.1 Agent系统 (`Agents_Experience/agents/`)
- **BaseAgent**: Agent抽象基类，定义决策接口
- **QwenAgent**: 基于Qwen大语言模型的Agent实现
  - 支持Function Calling机制
  - 多轮对话决策
  - 工具调用管理

#### 1.2.2 交易模拟器 (`Agents_Experience/core/simulator.py`)
- **TradingSimulator**: 核心模拟引擎
  - 时间循环控制（逐日模拟）
  - 交易执行与验证
  - 持仓价格更新
  - 交易成本计算（佣金、印花税）
  - 每日快照记录
  - 性能报告生成

#### 1.2.3 数据提供者 (`Agents_Experience/core/data_provider.py`)
- **MarketDataProvider**: 市场数据接口
  - 历史K线数据查询
  - 技术指标计算（MA、MACD、RSI）
  - 价格查询（确保不泄露未来数据）
  - 交易日验证

#### 1.2.4 交易工具集 (`Agents_Experience/core/tools.py`)
- **TradingTools**: Agent可调用的工具集合
  - `get_stock_history`: 获取历史K线
  - `get_technical_indicators`: 获取技术指标
  - `get_portfolio`: 查看持仓
  - `buy_stock`: 买入股票
  - `sell_stock`: 卖出股票

#### 1.2.5 投资组合管理 (`src/stock_app/portfolio.py`)
- **Portfolio**: 投资组合类
  - 持仓管理（Position）
  - 资金管理（现金、市值）
  - 盈亏计算
  - 账户摘要生成

## 3. AI智能投顾算法框架

### 3.1 整体决策流程

```
开始模拟
    ↓
初始化Agent和模拟器
    ↓
获取交易日列表
    ↓
┌─────────────────────────────────────┐
│     逐日循环 (For each trading day) │
└─────────────────────────────────────┘
    ↓
更新持仓价格 (Update Portfolio Prices)
    ↓
┌─────────────────────────────────────┐
│     Agent决策流程 (Agent Decision)  │
└─────────────────────────────────────┘
    ↓
    ├─→ 步骤1: 查看持仓 (get_portfolio)
    │       ↓
    │   分析仓位比例
    │       ↓
    ├─→ 步骤2: 数据收集 (Data Collection)
    │       ├─→ get_stock_history (多只股票)
    │       └─→ get_technical_indicators (技术指标)
    │       ↓
    ├─→ 步骤3: 技术分析 (Technical Analysis)
    │       ├─→ MA均线分析
    │       ├─→ MACD分析
    │       ├─→ RSI分析
    │       └─→ 成交量分析
    │       ↓
    └─→ 步骤4: 决策执行 (Decision Execution)
            ├─→ 买入决策 (buy_stock)
            │   ├─→ 检查买入条件
            │   ├─→ 验证资金充足
            │   └─→ 执行买入
            │
            ├─→ 卖出决策 (sell_stock)
            │   ├─→ 检查持仓
            │   ├─→ 检查卖出条件
            │   └─→ 执行卖出
            │
            └─→ 持有观望 (Hold)
                └─→ 不执行交易
    ↓
记录决策日志 (Log Decision)
    ↓
执行交易动作 (Execute Actions)
    ├─→ 计算交易成本
    ├─→ 更新持仓
    └─→ 更新资金
    ↓
记录每日快照 (Daily Snapshot)
    ↓
是否还有交易日？
    ├─→ 是 → 继续下一日
    └─→ 否 → 生成最终报告
    ↓
结束模拟
```

### 3.2 Agent决策详细流程

```
Agent.make_decision() 调用
    ↓
构建系统提示词 (System Prompt)
    ├─→ 角色定义
    ├─→ 股票池信息
    ├─→ 投资理念
    └─→ 工作流程说明
    ↓
构建每日决策提示 (Daily Prompt)
    ├─→ 当前日期
    ├─→ 账户信息（资金、持仓、收益率）
    └─→ 仓位比例
    ↓
初始化对话历史 (Messages)
    ├─→ System Message
    └─→ User Message (Daily Prompt)
    ↓
┌─────────────────────────────────────┐
│   多轮对话循环 (Max Iterations)     │
└─────────────────────────────────────┘
    ↓
调用Qwen API (Function Calling)
    ↓
解析API响应
    ↓
是否有工具调用？
    ├─→ 是 → 执行工具调用
    │       ├─→ get_stock_history
    │       ├─→ get_technical_indicators
    │       ├─→ get_portfolio
    │       ├─→ buy_stock
    │       └─→ sell_stock
    │       ↓
    │   将工具结果加入对话历史
    │       ↓
    │   继续下一轮对话
    │
    └─→ 否 → Agent完成决策
            ↓
        解析决策文本
            ├─→ 提取分析内容
            ├─→ 提取决策内容
            └─→ 提取理由
            ↓
        从工具调用中提取交易动作
            ├─→ buy_stock → actions['buy']
            └─→ sell_stock → actions['sell']
            ↓
        返回决策结果
            {
                'actions': [...],
                'analysis': '...',
                'reasoning': '...',
                'success': True
            }
```

### 3.3 技术指标计算流程

```
get_technical_indicators(symbol, current_date)
    ↓
获取历史数据 (get_stock_history, 60天)
    ↓
计算移动平均线 (MA)
    ├─→ MA5 = close.rolling(5).mean()
    ├─→ MA10 = close.rolling(10).mean()
    └─→ MA20 = close.rolling(20).mean()
    ↓
计算MACD指标
    ├─→ EMA12 = close.ewm(span=12).mean()
    ├─→ EMA26 = close.ewm(span=26).mean()
    ├─→ MACD = EMA12 - EMA26
    ├─→ Signal = MACD.ewm(span=9).mean()
    └─→ Hist = MACD - Signal
    ↓
计算RSI指标
    ├─→ delta = close.diff()
    ├─→ gain = (delta > 0).rolling(14).mean()
    ├─→ loss = (-delta < 0).rolling(14).mean()
    ├─→ rs = gain / loss
    └─→ RSI = 100 - (100 / (1 + rs))
    ↓
判断趋势信号
    ├─→ price_above_MA5
    ├─→ price_above_MA20
    ├─→ MA5_above_MA20
    ├─→ MACD_golden_cross (金叉)
    └─→ MACD_death_cross (死叉)
    ↓
返回指标字典
```

### 3.4 交易执行流程

```
执行买入 (execute_buy)
    ↓
获取股票价格 (get_stock_price_on_date)
    ↓
计算交易成本
    ├─→ trade_amount = price × quantity
    ├─→ commission = max(trade_amount × 0.0003, 5)
    └─→ total_cost = trade_amount + commission
    ↓
检查资金充足？
    ├─→ 否 → 返回失败
    └─→ 是 → 继续
    ↓
更新投资组合
    ├─→ portfolio.cash -= total_cost
    └─→ portfolio.add_position(symbol, quantity, price)
    ↓
记录交易日志
    ↓
返回成功

执行卖出 (execute_sell)
    ↓
检查持仓
    ├─→ 无持仓 → 返回失败
    └─→ 有持仓 → 继续
    ↓
检查持仓数量
    ├─→ 数量不足 → 返回失败
    └─→ 数量充足 → 继续
    ↓
获取股票价格
    ↓
计算交易收入
    ├─→ trade_amount = price × quantity
    ├─→ commission = max(trade_amount × 0.0003, 5)
    ├─→ stamp_tax = trade_amount × 0.0005
    └─→ total_revenue = trade_amount - commission - stamp_tax
    ↓
更新投资组合
    ├─→ portfolio.cash += total_revenue
    └─→ portfolio.reduce_position(symbol, quantity)
    ↓
记录交易日志
    ↓
返回成功
```

### 3.5 决策规则与策略

#### 3.5.1 仓位管理策略
| 当前仓位 | 操作建议 | 说明 |
|---------|---------|------|
| 0-30% | **积极买入** | 资金闲置是浪费，必须建仓 |
| 30-50% | 继续寻找机会 | 适度加仓 |
| 50-70% | 正常仓位 | 精选个股 |
| 70-80% | 谨慎加仓 | 注意风险控制 |
| >80% | 不再买入 | 等待卖出机会 |

#### 3.5.2 买入信号判断
- ✅ RSI < 50 且处于上升趋势
- ✅ RSI 在 30-50 区间（相对低位）
- ✅ MACD金叉（MACD线上穿信号线）
- ✅ 价格站上MA5均线且MA5向上
- ✅ 近期连续下跌后企稳（跌幅>5%后出现阳线）
- ✅ 成交量放大且价格上涨（量价配合）

#### 3.5.3 卖出信号判断
- 🚨 **强制卖出**（满足任一即卖）：
  - 亏损达到 -8% 或以上（止损）
  - 盈利达到 15% 或以上（止盈）
  - RSI > 75（极度超买）
  - MACD死叉且盈利

#### 3.5.4 风险控制规则
1. **单只股票仓位限制**: 不超过总资产的30%
2. **分散投资**: 持有3-5只不同板块的股票
3. **严格止损止盈**: 亏损-8%止损，盈利15%止盈
4. **T+1规则**: 今天买入的股票明天才能卖出

### 4.4 工具模块 (`Agents_Experience/core/tools.py`)

#### 4.4.1 TradingTools 类概述

`TradingTools` 是Agent可调用的交易工具集合，采用OpenAI Function Calling标准格式定义，使Agent能够通过大语言模型的工具调用机制来执行交易相关操作。

```python
class TradingTools:
    - data_provider: MarketDataProvider实例，提供市场数据
    - stock_pool: 股票池列表
    
    def get_tools_definition():
        - 返回OpenAI Function Calling格式的工具定义列表
        - 包含5个工具：数据查询类（3个）+ 交易执行类（2个）
    
    def execute_tool(tool_name, arguments, current_date, portfolio):
        - 执行指定的工具调用
        - 返回JSON格式的执行结果
        - 处理错误并返回友好的错误信息
```

#### 4.4.2 Agent调用工具的场景

Agent在每日决策过程中，会根据需要主动调用不同的工具来获取信息或执行交易。工具调用的典型场景如下：

##### 场景1：决策前信息收集
在做出交易决策之前，Agent通常需要：
1. **查看当前持仓** (`get_portfolio`)
   - 了解当前资金状况
   - 查看持仓股票及盈亏情况
   - 计算仓位比例，判断是否需要调整

2. **获取股票历史数据** (`get_stock_history`)
   - 分析股票价格走势
   - 查看成交量变化
   - 了解近期涨跌情况

3. **获取技术指标** (`get_technical_indicators`)
   - 分析MA均线系统（MA5、MA10、MA20）
   - 查看MACD指标（判断金叉/死叉）
   - 分析RSI指标（判断超买/超卖）
   - 综合技术面信号

##### 场景2：执行交易决策
在完成信息收集和分析后，Agent会：
1. **买入股票** (`buy_stock`)
   - 当发现买入信号时（如MACD金叉、RSI低位、价格站上均线等）
   - 验证资金充足性
   - 计算交易成本

2. **卖出股票** (`sell_stock`)
   - 当触发卖出条件时（止损、止盈、技术面转弱等）
   - 验证持仓数量
   - 遵守T+1交易规则

##### 场景3：多轮工具调用流程
Agent支持多轮对话和工具调用，典型流程如下：

```
第1轮：调用 get_portfolio → 了解当前状态
第2轮：调用 get_stock_history(股票A) → 查看股票A历史
第3轮：调用 get_technical_indicators(股票A) → 分析股票A技术面
第4轮：调用 get_stock_history(股票B) → 查看股票B历史
第5轮：调用 get_technical_indicators(股票B) → 分析股票B技术面
第6轮：调用 buy_stock(股票A) → 执行买入决策
第7轮：Agent完成决策，输出分析报告
```

#### 4.4.3 工具调用机制

##### Function Calling 流程

1. **工具定义注册**
   - `TradingTools.get_tools_definition()` 返回工具定义列表
   - 每个工具定义包含：名称、描述、参数schema
   - 传递给Qwen API，让模型知道可用的工具

2. **Agent发起工具调用**
   - Agent在对话中决定需要调用哪个工具
   - Qwen API返回 `tool_calls` 字段，包含工具名称和参数

3. **工具执行**
   - `TradingTools.execute_tool()` 执行具体的工具逻辑
   - 访问数据提供者或投资组合
   - 返回JSON格式的执行结果

4. **结果反馈**
   - 工具执行结果作为 `tool` 角色的消息加入对话历史
   - Agent根据工具结果继续分析或做出最终决策

##### 时间控制机制

- **严格的历史数据访问**：工具只能访问 `current_date` 及之前的数据
- **防止未来数据泄露**：`MarketDataProvider` 确保不会返回未来数据
- **实时价格获取**：交易工具使用 `current_date` 的收盘价进行交易

##### 工具4：buy_stock（买入股票）

**功能描述**：执行买入操作，验证资金充足性，计算交易成本，返回买入准备信息。

**调用场景**：
- Agent分析后认为某只股票有买入机会
- 技术指标显示买入信号（如MACD金叉、RSI低位等）
- 当前仓位较低，需要建仓或加仓

**参数说明**：
- `symbol` (string, 必填): 股票代码
- `quantity` (integer, 必填): 买入数量（股），必须是100的整数倍（1手=100股），最小100股

**验证规则**：
1. 数量必须是100的整数倍
2. 资金必须充足（价格×数量+佣金）
3. 只能买入股票池中的股票

**返回数据（成功）**：
```json
{
  "action": "buy",
  "symbol": "000001",
  "quantity": 1000,
  "price": 12.70,
  "estimated_cost": 12838.81,
  "message": "准备买入 000001 1000股，预计花费 12,838.81 元"
}
```

**返回数据（失败）**：
```json
{
  "error": "资金不足！需要 128,388.10 元，可用 50,000.00 元"
}
```

**交易成本计算**：
- 佣金 = max(交易金额 × 0.0003, 5元)
- 总成本 = 价格 × 数量 + 佣金

**注意事项**：
- 此工具只返回买入准备信息，实际执行由 `TradingSimulator` 处理
- 买入后需要遵守T+1规则（今天买入的明天才能卖）

##### 工具5：sell_stock（卖出股票）

**功能描述**：执行卖出操作，验证持仓数量，计算交易收入，返回卖出准备信息。

**调用场景**：
- 触发止损条件（亏损达到-8%）
- 触发止盈条件（盈利达到+15%）
- 技术指标显示卖出信号（如MACD死叉、RSI超买等）
- 需要调整仓位或换股

**参数说明**：
- `symbol` (string, 必填): 股票代码
- `quantity` (integer, 必填): 卖出数量（股），最小100股

**验证规则**：
1. 必须持有该股票
2. 持仓数量必须足够
3. 遵守T+1规则（今天买入的股票今天不能卖）

**返回数据（成功）**：
```json
{
  "action": "sell",
  "symbol": "000001",
  "quantity": 1000,
  "price": 12.70,
  "estimated_revenue": 12678.24,
  "message": "准备卖出 000001 1000股，预计收入 12,678.24 元"
}
```

**返回数据（失败）**：
```json
{
  "error": "持仓不足！持有 500 股，卖出 1000 股"
}
```

**交易成本计算**：
- 佣金 = max(交易金额 × 0.0003, 5元)
- 印花税 = 交易金额 × 0.0005（仅卖出收取）
- 实际收入 = 价格 × 数量 - 佣金 - 印花税

**注意事项**：
- 此工具只返回卖出准备信息，实际执行由 `TradingSimulator` 处理
- 必须遵守T+1交易规则

#### 4.4.5 工具调用的错误处理

所有工具调用都包含完善的错误处理机制：

1. **参数验证错误**
   - 股票代码不在股票池中
   - 买入/卖出数量不符合规则
   - 返回友好的错误信息

2. **数据获取错误**
   - 股票数据不存在
   - 历史数据不足（技术指标计算需要至少20天数据）
   - 返回明确的错误原因

3. **业务逻辑错误**
   - 资金不足
   - 持仓不足
   - T+1规则违反
   - 返回详细的错误说明

4. **异常捕获**
   - 所有工具调用都使用 try-except 包裹
   - 捕获异常并返回JSON格式的错误信息
   - 确保Agent能够理解错误原因

#### 4.4.6 工具调用的最佳实践

1. **信息收集顺序**
   - 先调用 `get_portfolio` 了解整体状况
   - 再调用 `get_stock_history` 查看价格走势
   - 最后调用 `get_technical_indicators` 进行技术分析

2. **多股票分析**
   - 可以依次调用多个股票的数据查询工具
   - 对比分析不同股票的技术面
   - 选择最优的买入/卖出标的

3. **交易执行**
   - 在充分分析后再调用 `buy_stock` 或 `sell_stock`
   - 注意验证资金和持仓的充足性
   - 考虑交易成本对收益的影响

4. **错误处理**
   - Agent应该能够理解工具返回的错误信息
   - 根据错误信息调整决策（如资金不足时减少买入数量）
